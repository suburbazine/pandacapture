PandaCapture launchers for Windows

Put these .cmd files in the same folder as pandacapture.exe, then double-click one:

  PandaCapture Dashboard.cmd   live dashboard (Kia Stinger map), recording the drive
  PandaCapture Record.cmd      record only; M = marker, Q = stop and save
  PandaCapture Check.cmd       is the panda connected and powered?

For a desktop or taskbar shortcut: right-click a .cmd file, then Show more options > Send to >
Desktop (create shortcut). To change what a launcher starts, right-click it > Edit: the options are
explained at the top of the file.

Captures go to the "captures" folder next to pandacapture.exe.
