A page for building extra tools onto PandaCapture without touching the gauges. Everything a tool needs to reach the running dashboard is ready on window.PCDev (and units on window.PCUnits): the live values, the address map, the JSON API and small helpers to mount UI in the app's style. Grab a hook below, or drop a tool into the build area at the bottom. This runs on your computer only.

Add a tool

For a session building onto this page.

  1. Client-only tool: drop a <script> into the build area below (or a new section) and use PCDev. No server change needed if the data is already served.
  2. New data from the car or files: add a route in pandacapture/dashboard.py — a GET branch in do_GET (or do_POST for an action), returning self._json(...); gate anything that reaches the key, writes files or costs money behind self._local(). Read live values under state.lock.
  3. A whole new page (like this one): add <name>.html under pandacapture/web/, read it in make_handler, serve it from a do_GET branch, and add a header link on the other pages. Static assets (JS/SVG) go in the icons map. The web/ folder is packaged whole, so new files ship with no build change.
  4. Keep the tests green: python -m pytest.

Build area

No extra tools yet. A developer session adds them here — see Add a tool above. Quick start: const s = PCDev.panel("My tool"); PCDev.onSignal("rpm", (v) => s.textContent = v);
