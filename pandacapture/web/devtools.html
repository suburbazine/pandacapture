Developer Tools

connecting…

A page for building extra tools onto PandaCapture without touching the gauges. What a tool needs to reach the running dashboard is ready on window.PCDev, and the units setting on window.PCUnits: the live values, the address map, the JSON API, and helpers to mount UI in the app's style. Grab a hook below, or add a tool to the build area at the bottom.

The dashboard has no sign-in. It answers this computer only, unless it was started with --lan: then anyone on the network can use it, these hooks included. Of the actions, only the Claude routes and the bundle download refuse other devices.

Hooks

Ready-made building blocks, each running live on this page: call one from a tool, or copy its snippet. A live hook returns stop(); call it when the tool goes away. Live hooks share one connection per feed, so subscribe as often as a tool needs.

API endpoints

What the dashboard serves. PCDev.get and PCDev.post wrap these (post sends JSON; for a CSV body, call fetch with the file). To add one, see the recipe below.

Add a tool

For a session building onto this page.

  1. A tool from data already served: add a section and a <script> to the build area below, using PCDev. No server change.
  2. New data or a new action: add a branch to do_GET (or do_POST for an action) in pandacapture/dashboard.py, answering with self._json(...). Read live values under state.lock. Anything that spends money on the API key or hands over a capture is limited to this computer with self._local(), as the Claude routes and the bundle download are.
  3. A page of its own (as this one is): add <name>.html to pandacapture/web/, read it in make_handler, answer it in do_GET, and link it from the other pages' headers. Scripts and images go in the icons map. The web/ folder is packaged whole, so new files ship with no build change.
  4. The dashboard reads its pages when it starts: restart it to see a change. Keep the tests passing (python -m pytest), and add one for a new route.

Build area

No extra tools yet: a developer session adds them here (see Add a tool above). To start: const s = PCDev.panel("My tool"); PCDev.onSignal("rpm", (v) => s.textContent = v);
