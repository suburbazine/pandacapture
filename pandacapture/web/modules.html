Modules (UDS)

Finds every module that answers diagnostic requests (each id from 700 to 7F7, about 20 s a bus), then reads what each is (part, hardware and software numbers) and its own trouble codes. Only key-on or at idle: the search won't start, and stops, above 900 rpm. Reads only: nothing is cleared or changed.

These send requests on the vehicle's bus, so they work from the computer running PandaCapture only.
Sending needs a panda with PandaCapture firmware being read by the gauges (see Firmware).

Data by identifier (UDS 22) from one module, at any engine speed. Click a module above to fill it in.
