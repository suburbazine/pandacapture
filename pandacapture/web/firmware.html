Flash

PandaCapture's firmware is the panda project's own, with a gate that lets frames out only when PandaCapture arms it on purpose: it listens silently otherwise.

Flashing works from the computer running PandaCapture only: open this page there.
A recording is running: stop it on the gauges first.
Pick a panda above.

Working

Keep the panda plugged in and powered until this says it's done. The gauges pause meanwhile.


    

  


  

    
Backups

    
Before the first install replaces a panda's bootstub, its whole flash is saved here: bootstub,
      firmware and settings, byte for byte, so a clone maker's or fork's firmware can be put back exactly.

If it stops

    
    
      
  • On Windows, the first install needs a driver for the STM32 bootloader (USB 0483:DF11): install WinUSB for it with Zadig
        (see "Windows driver" in the README), then flash again. Nothing is erased before that step.
    • 
      
  • Unplugged or interrupted? Plug it back in and flash again: a panda left in its bootstub or the bootloader carries on
        from there.
    • 
      
  • Other firmware back: restore its backup from the list above.
